# 任务形态与写法

渲染走 `dsh-ui` 围栏。格式：

````
```dsh-ui
{"title":"可选标题","gap":14,"items":[ ...组件... ]}
```
````

规则：
- 顶层是**一个对象**，组件全在 `items` 数组里。
- 数学用 `$...$`（行内）/ `$$...$$`（独立）。**JSON 字符串里的反斜杠要双写**：`"content": "\\(\\frac{a}{b}\\)"`。
- 所有面向学习者的文字**跟随对话语言**。JSON 的键名、组件 type、id、action 保持英文不动。
- 围栏只放可操作对象；问句和教学文字放在围栏**外面**。

---

## 形态 A：实时函数探究（旗舰做法，零往返）

**`plot` 组件自带参数滑块，拖动即时重绘——不需要模型参与，没有往返。** 这是本产品最核心的一个组件，凡是可以写成 `f(x)` 的关系都优先用它。

```json
{"type":"plot","title":"阻尼振动","xMin":0,"xMax":12,
 "series":[{"expr":"A*exp(-d*x)*sin(w*x)","label":"位移","params":[
   {"name":"A","value":1,"min":0.2,"max":2},
   {"name":"d","value":0.2,"min":0,"max":1.5},
   {"name":"w","value":3,"min":0.5,"max":8}
 ]}]}
```

**表达式词汇表**（超出这个范围的就是写不出来，别硬凑）：

- 函数：`sin cos tan asin acos atan sqrt cbrt exp log ln abs floor ceil round min max pow`
- 常量：`pi e tau`
- 自变量**固定叫 `x`**
- 幂用 `^`（`x^3`、`(x-m)^2` 都合法）

**两条会静默失效的硬约束**（解析失败时**什么都不画，也不报错**，你只会看到一张空图）：

1. **参数只能是单个字母。** `A` `d` `w` `s` `m` `k` `a` `b` `c` 可以；`sigma`、`alpha`、`rate`、`n0` **不行**——多字符标识符是解析错误。想表达 σ 就用 `s`，用 `label` 字段写清它是标准差。
2. **表达式里出现的每个字母，都必须在 `params` 里声明。** 写了 `A*exp(-d*x)` 却只声明 `d`，`A` 就是未识别标识符。

发布前自己检查一遍：**所有参数名都是单个字母，且都出现在 `params` 数组里。**

### 用 `animateTo` 让参数自己走一遍

参数带 `animateTo` 会显示播放按钮，自动从 `value` 动到 `animateTo`。适合"先让他看全过程，再让他自己拖"。

```json
{"name":"n","value":1,"min":1,"max":20,"animateTo":20,"durationMs":4000}
```

### 参数范围怎么选（这一步决定任务成不成立）

- **范围必须覆盖"翻转点"**：如果他只能看到单调变化，就没有预测可押。要让他能拖出**定性的改变**（峰值从宽变窄、从单调变振荡、从收敛变发散）。
- **别给一堆参数**。一个任务一个变量；确需第二个，把它固定在某个值上并在文字里说明。
- **y 轴锁定**是特性不是限制：只变曲线不变数轴，他才能比较形状。但这也意味着量级变化极大时曲线会飞出视野——**自己先估一遍范围**。

#### 峰值会被切掉——必须显式给 `yMax`

`plot` 支持 `yMin` / `yMax`，但**不写就自动取范围，而自动范围常常把最高点切掉**。
这不是小瑕疵：如果任务问的就是"峰值多高"，一张看不到峰顶的图会让整个任务失效。

**自己算一遍峰值**，然后给 `yMax` 留出余量。各参数取值范围的两端都要算，取最大的那个。

```json
{"type":"plot","xMin":-5,"xMax":5,"yMin":0,"yMax":0.5,
 "series":[{"expr":"1/(s*sqrt(2*pi))*exp(-((x-m)^2)/(2*s^2))","label":"概率密度",
   "params":[{"name":"s","value":1,"min":0.4,"max":2},{"name":"m","value":0,"min":-2,"max":2}]}]}
```

对上式：峰值 = `1/(s*sqrt(2*pi))`。`s` 最小取 0.4 时峰值约 1.0，所以 `yMax` 至少 1.0。
**先算，再写。**

> 这条是实测踩出来的：一个正态分布的探究任务里，`s` 的范围含 1（峰值 ≈ 0.4），
> 而组件自动把 y 轴定到 0.2 —— 峰顶整块被切在框外，学习者在图上**根本看不到题目问的那个量**。

**一条判据**：写完 `plot` 后问自己"这张图上最重要的那个特征，在框里完整吗？"
如果任务问的是峰值、谷值、交点或是否越界，就要保证那个位置在视野内。

### 什么时候不能用

`plot` 只能画**单变量函数的连续曲线**。以下情况用形态 B：
- 离散/组合对象（算法步数、递归树规模、图结构）
- 需要真实数据而非公式的（实验数据、真实分布样本）
- 多变量同时呈现的曲面

### 常见可写形态（起手参考，别照抄）

| 想让他感受 | 表达式骨架 |
| --- | --- |
| 振幅/频率/相位各自的作用 | `A*sin(w*x + p)`，参数 `A` `w` `p` |
| 阻尼 | `A*exp(-d*x)*sin(w*x)` |
| 正态分布的胖瘦与位置 | `1/(s*sqrt(2*pi))*exp(-((x-m)^2)/(2*s^2))`，参数 `s` `m` |
| logistic 的陡峭与阈值 | `1/(1+exp(-k*(x-t)))` |
| 幂律 vs 指数 | 同图两条 series：`x^a` 与 `exp(b*x)` |
| 多项式根的个数 | `a*x^3 + b*x^2 + c*x + d`，一次只放一个参数 |
| 波叠加 | 两条 series `sin(x)` 与 `sin(k*x)` |

## 形态 B：预计算族（离散/数据类，零往返）

状态不是一条曲线时，**一次把整族摊开**，让他在图例/缩放/标签页里自己走。

```json
{"type":"echart","title":"不同样本量下的分布","preset":"line",
 "series":[{"label":"n=5","data":[{"label":"0","value":3}]},
           {"label":"n=50","data":[{"label":"0","value":11}]}]}
```

可用的本地探索手段（都是零往返）：
- `echart`：图例点选、`dataZoom` 缩放、tooltip —— **多序列是"族"的最小表达**
- `tabs` / `accordion`：状态离散且差异大时，每个 tab 一个状态
- `table`：加 `"filter":"<某个 input/select 的 id>"` 可让学习者**输入即时过滤**（本地）
- `chart`：≤8 个点的轻量对比（无额外下载）

## 形态 C：单点探针（一次往返）

用于**状态无法用表达式表达**、而学习者只需要验证一个具体判断时。给一个 `slider` 或 `select` 带 `action`，他选值，下一轮你返回那一个状态。

```json
{"type":"slider","label":"你猜多少个样本时它会稳定下来","min":1,"max":200,"step":1,
 "id":"n","action":"probe"}
```

代价是**每次操作花掉一个回合**。所以：
- 只在**一次就能给出关键信息**时用。
- 他想连续扫一串值 → 改用形态 A 或 B，别陪他一个个试。
- 拖拽会防抖合并成一次 action，不会刷屏。

## 形态 D：本地自检（收尾专用，零往返）

选择题答对答错**当场在界面上出现**，不用等你。**只用来收尾，别当主菜**——所有同类产品都在做这个。

单题：
```json
{"type":"quiz","question":"阻尼增大时，包络线的衰减速度怎么变？",
 "options":[{"label":"变快","correct":true,"feedback":"对——指数项衰减更陡"},
            {"label":"变慢","feedback":"再看一眼 exp(-d*x) 里 d 的位置"}],
 "explanation":"包络是 exp(-d*x)，d 越大衰减越快。"}
```

多题成卷（每题一个带 `group` 的 `radio` + `answer`，末尾一个 `submit` 统一交卷，**分数当场出现**）：
```json
{"type":"radio","group":"q1","label":"…","options":["…","…"],"answer":1,"explanation":"…"}
{"type":"submit","label":"交卷","action":"grade","groups":["q1","q2"]}
```

> 注意：`explanation` 会在判题后显示。**如果这道题本身是探究的一部分，别用 `feedback`/`explanation` 提前泄底**——留给对质环节用普通文字讲。

## 降级：没有渲染器的时候

围栏会原样显示成代码块。**任务必须照样成立**：

- 问句和关键数值放在**围栏外**的普通文字里
- 形态 A 降级：直接把表达式和几组代表性参数值写出来，请他手算或心算比较
- 形态 C 降级：直接问"你想把 n 设成几"，然后自己算
- 形态 D 降级：把选项列成普通列表，让他回答，你判

**永远不要因为画不出来就卡住，也不要提"图没渲染出来"**——他可能根本看不到你预期的那个图。
